## 轉換（喺你部 Mac 跑一次）

```bash
cd ~/Downloads/pmwire
source .venv/bin/activate
python tools/import_ledger.py ~/Downloads/hk_racing_pipeline/output/pm_paper_ledger.csv
```

佢會：
- 讀你原本個 CSV
- 補上 `current_p`（初值 = `entry_p`）、`marked_at`、`category`
- 寫入 `state/pm_paper_ledger.csv`
- **唔會改任何 `entry_p`、`outcome`、`pnl`** —— 已結算嘅三筆原樣保留

然後：

```bash
python src/run.py scan          # 即刻 mark-to-market，攞今日價
bash tools/update.sh "add public ledger"
```

## 之後
