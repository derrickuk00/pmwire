## 一、先講最重要嘅發現：你 scan (A) 應該改變定位

### 數據

2026 年一份 arXiv 研究（Polymarket **2.2 億筆交易、113,483 個市場**，數據到 2025-12-31）
量度各領域嘅**校準斜率 b**。b > 1 代表價格「唔夠極端、被壓縮向 50%」，
即係**冷門被高估、熱門被低估**：

| 領域 | 斜率 b |
|---|---|
| **政治** | **1.31** |
| 加密 | 1.05 |
| 體育 | 1.08 |

而且斜率隨時間軸惡化：**1 小時內 0.99 → 一個月以上 1.32**。

另一份研究（28,407 個已結算市場，2024-01 至 2026-05）：整體平均校準誤差 2.1 個百分點，
但**極端價位有明顯 long-shot bias（5 仙市場實際只有約 4.5% 結算 YES）**。

### 對你嘅意思

你 scan (A) 嘅三個篩選條件係：
1. **政治/地緣** ← 斜率最差嘅領域（1.31）
2. **0.10–0.35** ← 冷門端，偏差最大
3. **長期未結算** ← 時間軸最長，斜率最差（1.32）

**呢個係文獻識別出嚟最差三個條件嘅交集。** 你 3/3 全 NO 唔係運氣差 ——
係模型預測到嘅結果。你個 ledger 而家寫住 ROI −100%，實際上佢係喺
**成功複製一個學術發現**。

### 所以點做

**唔好當佢係選股器。當佢係測量儀器。**

| 舊定位 | 新定位 |
|---|---|
| 「呢啲平嘅 YES 值唔值博」 | 「政治冷門系統性高估幾多？我實測緊」 |
| 帳本 = 戰績（−100% 好核突） | 帳本 = 實驗記錄（3/3 全 NO = 預期之內） |
| 內容 = 推介（❌ 監管紅線） | 內容 = 公開複製實驗（✅ 完全安全） |

**呢個係你成個項目最強嘅內容資產。** 冇人喺公開場合、用可審計嘅帳本、
逐日實測緊呢個偏差。100 日之後你手上有一個獨一無二嘅數據集，
而且每一日都有嘢報告 —— 因為「今日又點」本身就係內容。

⚠️ **但要即刻做一件事：** 你 42 個 pending 冇 mark-to-market。
政治市場幾個月先結算，100 日內大部分仍然 pending，你學唔到嘢。
**必須每日 snapshot 每個 pending 嘅現價**，咁你先可以報告
「呢籃 42 個入場均價 0.22，今日均價 0.19，−3 個百分點」——
呢個就係每日都有嘅實質內容，唔使等結算。

## 三、內容分層（15 篇點砌）

```
┌─ Tier 1：每日錨定貼（1 篇，固定時間，永遠有）─────────────┐
│  「效率讀數」                                              │
│  掃描 N 個 negRisk board、Σask 中位 X、Σbid 中位 Y、       │
│  M 個階梯家族、K 個違規。同基準日對比。                     │
│  → 格式完全固定 → 變成一個可追蹤嘅系列 → 有人為咗個數字而追  │
└────────────────────────────────────────────────────────┘

┌─ Tier 2：事件觸發（0–3 篇，罕有但最強）──────────────────┐
│  A. 階梯違規命中：「X by 6月 報 0.34，X by 12月 報 0.31。  │
│     遲 deadline 唔可能低過早 deadline。差 3 點。」          │
│     ← 可證偽、可審計、任何人自己去查得到 = 最強原創性       │
│  B. Board Σask < 0.98 或 > 1.06                            │
│  C. 極端異動（>15 個百分點）                                │
└────────────────────────────────────────────────────────┘

┌─ Tier 3：籃子追蹤（1 篇/日）────────────────────────────┐
│  「政治冷門籃：42 個持倉，入場均價 0.22，今日 0.19。       │
│   已結算 3/3 全 NO。文獻預測政治斜率 1.31。」               │
│  ← 逐日複製學術發現，100 日成為獨有數據集                   │
└────────────────────────────────────────────────────────┘

┌─ Tier 4：異動註記（填數量，3–10 篇）────────────────────┐
│  原 pmwire 嗰套：邊個市場郁咗、盤口深淺、幾個未證實假設     │
└────────────────────────────────────────────────────────┘

┌─ Tier 5：每週一篇（週日）───────────────────────────────┐
│  方法論 / 陷阱筆記。例如：                                  │
│  「Polymarket 嘅 endDate metadata 唔可信。實例 677273       │
│   寫 2025-12-31 但題目講 2026。我而家一律 parse 題目。」     │
│  ← 呢類「我踩過嘅坑」內容互動率最高，而且建立可信度         │
└────────────────────────────────────────────────────────┘
```

**你已經有 Tier 5 嘅材料：** endDate 陷阱、「by market cap」假陽性、
